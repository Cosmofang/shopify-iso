# App 内营销 Marketing

> Shopify Admin 首先是商家工作的地方。品牌表达保持克制；评分请求、套餐升级和其他 App 推广不能干扰主任务，并同时通过 BFS 4.3.1、4.3.2、4.3.3、4.3.6 和 4.3.7。

## 品牌表达

- 用轻量插图和图片表达品牌，常用布局、Card、按钮和表单仍跟随 Shopify Admin。
- 不用整页品牌背景、强烈渐变或自绘 chrome 让 App 与 Admin 脱节。
- 图标和 AI 视觉不得冒充 Shopify、Sidekick 或 magic purple。

## 促销位置

- 首页促销放在工作内容之后的可关闭 Card/gallery，或建立独立促销页。
- 不把促销、评分请求或支持链接混进当前主任务的 primary action group。
- 不在每个页面重复同一营销消息，也不让促销自动弹 modal/popover。
- 关闭状态按相关商家/店铺身份持久化；同一或相似促销关闭后不能在后续会话换皮重现。

## 文案与行为边界

- 不承诺、保证或强烈暗示销售、排名、转化等结果。
- 不用虚假评论、假优惠、倒计时、羞辱式拒绝文案或其他施压方式。
- 不以奖励交换五星评价；展示其他 App 的评分必须与当前 App Store 评分一致。
- 红色不用于促销、价格或 CTA，动画不用于持续吸引商家升级或评价。

## Plan-gated features

- 套餐限定功能在视觉与功能上都准确禁用，并就近明确标注解锁所需的具体套餐。
- 不能让功能可点击但看似禁用，也不能看似可用却不可点击或提交后才揭示付费限制。
- Shopify Plus 专属功能对非 Plus 商家完全隐藏，不只是 disabled。
- Subdued/灰色是官方推荐表达，但 BFS 的核心是视觉态、交互态和套餐说明一致，不规定唯一颜色实现。

## 验收

- [ ] 所有 promotion 可关闭，刷新、重新登录和后续会话不再出现同类内容
- [ ] 页面主 CTA 与营销/评分/支持动作分离
- [ ] 全 App 无自动促销浮层、倒计时、施压或结果承诺
- [ ] 每个 plan-gated 功能的视觉、交互、提示与 entitlement 一致
- [ ] 非 Plus 商家看不到 Plus-exclusive 功能
